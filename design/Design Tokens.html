Design tokens — Tailwind handoff

Everything you need to hand-write a Tailwind config that matches the Portfolio.html design exactly: colors, type scale, spacing, radii, borders, shadows, motion. Copy values, don't copy code — you asked to wire it up yourself.

Colors

All defined in OKLCH for perceptual consistency. Hex approximations provided for tooling that doesn't support OKLCH yet (Tailwind v4 does natively; v3 needs the hex).

Borders, radii, shadows

Borders

width1px (always)
colorvar(--rule)
accent2px solid var(--accent) for active tab underline
accent-dim2px solid var(--accent-dim) for expanded card left-rail

Radii

rounded-none0everything (no rounding)
rounded-full50%status dots only (8px / 6px)
Rule: this design uses zero rounded corners on containers, chips, buttons, and panels. Only tiny status dots are round. Enforce this by removing default radii.

Shadows

No drop shadows anywhere. Elevation is expressed with background shifts (bg → bg-elev) and borders only. This is deliberate — don't add them.

Tailwind hints (read, don't copy)

Naming suggestions so your tailwind.config lines up with how the design talks about itself. Pick what fits your setup.

Colors namespace

// suggested token names for your config
surface:     bg, bg-elev, bg-line
content:     fg, fg-dim, fg-mute, fg-faint
line:        rule
accent:      accent (default), accent-dim
syntax:      info (blue), str (orange), warn (amber)

Font families

font-mono: 'JetBrains Mono', ui-monospace, monospace    // default everywhere
font-sans: 'Inter', -apple-system, system-ui, sans-serif // .prose only

Global base styles you'll want

/* body */
background: var(--bg);
color: var(--fg);
font-family: 'JetBrains Mono', ui-monospace, monospace;
font-size: 14px;
line-height: 1.6;
-webkit-font-smoothing: antialiased;
font-feature-settings: "ss01", "ss02", "cv11";

/* selection */
::selection { background: var(--accent); color: var(--bg); }

/* reset radii if using default Tailwind preflight */
button, input, .card { border-radius: 0; }
That's the full system. Colors, type, spacing, borders, motion — everything Portfolio.html uses. Translate these into tailwind.config.js theme.extend and you'll be matched pixel-for-pixel.
